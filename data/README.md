# Данные

Строение — здесь, в JSON; длинные тексты — в `texts/` (Markdown). Сборка склеивает их в глобальные переменные
страницы: `node tools/data.js --emit` (это делает `tools/build.py`). Проверка: `node tools/validate.js`.

Годы — от Завоевания (до Завоевания — отрицательные). В строках годов можно писать `'256–263'`, `'245/246'`,
`'не позднее 237'`, `'≈286'`, `'в детстве'`, `'в младенчестве'`. Примечание к браку вида «N г.» читается как год брака,
поэтому в других примечаниях «г.» после числа не ставится.

## Файлы

| файл | что внутри | на странице |
|---|---|---|
| `meta.json` | `now_year`, `people_files` (порядок файлов людей), `bands`, `houses`, `gaps` | `NOW_YEAR`, `BANDS`, `HOUSES`, `GAPS` |
| `people/<файл>.json` | люди, по группам: `{ title, about, groups: [{ title, people: [...] }] }` | `PEOPLE` |
| `dragons.json` | `origins` (ветви), `groups` с драконами, `fights` | `DRAGON_ORIGINS`, `DRAGONS`, `DRAGON_FIGHTS` |
| `screen.json` | `series`, `groups` с ролями: `{ id, a }` | `SERIES`, `EXTRA.screen` |
| `vassals.json` | вкладка «Вассалитет»; собирается `node tools/vassals-build.js` из `research/vassal/*.json`, руками не править | `V_REGIONS`, `V_PRE`, `V_CLAIMANTS`, `V_MILESTONES`, `V_HOUSES` |

Тексты: `texts/people/<файл>.md` — описания людей (`t`), `texts/dragons.md` — описания ветвей и драконов (`t`),
`texts/screen.md` — чем сериал отличается от книг у людей (`df`), `texts/screen-dragons.md` — то же у драконов
(`DRAGON_SCREEN`). Раздел текста — `### id · Имя`; `✎` в конце заголовка — текст написал Claude (черновик,
на странице `ai: 1`, пометка «✎ Черновик Claude» и линза «Тексты Claude»).

Порядок важен: люди собираются в `PEOPLE` в порядке `people_files`, внутри файла — по группам сверху вниз;
в этом же порядке стоят дети одного родителя на древе и идёт поиск по имени.

## Человек (`people/*.json`)

| поле | что значит |
|---|---|
| `id` | латиницей, уникальный |
| `name`, `full` | имя на древе; полное имя (с прозвищем или титулом), если отличается — должно быть уникальным |
| `en` | имя по-английски, для поиска на A Wiki of Ice and Fire |
| `al` | другие имена и прозвища, для поиска |
| `fem` | 1 — женщина (для слов в карточке и поиска родства) |
| `group` | 1 — группа людей одной карточкой (без пола, не считается в «живых») |
| `hs` | дом: `targ` (по умолчанию; у `k: 'B'` — `bf`), `vel`, `bar`, …, `oth` — другой дом, тогда `h` — какой («Редвинов») |
| `k` | положение: `K` король, `C` претендент, `R` бастард, `B` Блэкфайр, `T` прочие |
| `pre` | 1 — до Завоевания (владыки Драконьего Камня) |
| `n`, `r`, `rm` | номер короля, годы правления, особая подпись правления («на троне с 300») |
| `pr`, `su` | предшественник и преемник на троне, если не по номеру |
| `cl` | Блэкфайр-претендент |
| `kl` | титул в подписи после дома («Король Севера») |
| `p` | родитель, под которым человек стоит на древе (корни ветвей — в `meta.json`, `bands`) |
| `par` | оба родителя: id или текст; пометки в скобках: `'robert (официально)'` |
| `rp` | родитель по слухам из другого дома; `unc` — родство не подтверждено |
| `b`, `d` | годы рождения и смерти |
| `dr` | дракон (подпись в карточке) |
| `sp` | супруги: `[ссылка, примечание, тип]`; тип `m` брак (по умолчанию), `b` помолвка, `l` связь вне брака |
| `wd` | воспитанники |
| `ev` | события: `[год, текст, ссылка]` |
| `wiki` | запрос для A Wiki of Ice and Fire, если английского имени нет или оно неоднозначно |

## Полосы, дома, пропуски (`meta.json`)

- `bands` — полосы древа: `{ house, roots: [[id корня, колонка поколения]] }`. Колонка ≈ год рождения:
  6 ≈ −20, 8 ≈ 34, 10 ≈ 88, 12 ≈ 123, 14 ≈ 172, 16 ≈ 198, 18 ≈ 245, 19 ≈ 269, 20 ≈ 286.
  `sub` — у малого дома: id великого дома, внутри полосы которого он стоит (свёрнутым, пока его не развернут).
  Первая полоса (Таргариены) всегда наверху; остальные великие дома (вместе с их малыми) страница расставляет сама
  так, чтобы линии браков и других связей между домами были в сумме короче, поэтому порядок здесь не важен.
  Колонки, где больше 40 человек, шире обычных.
- `houses` — `{ name, band, motto, sigil: { field, charge } }`; `band` есть только у домов с полосой на древе.
  `gar`, `dur`, `hoa` — королевские дома до Завоевания, только для вкладки «Вассалитет»; `seed` — «Семя дракона».
  У малого дома обычно нет герба (`sigil` не задаётся); большим малым домам, как Фреям, герб задаётся. Цвета малый
  дом берёт у великого дома из `sub`, или из `tone`, если встречается без своей полосы.
- `gaps` — пропуски в родословной: `{ house, from, to, years, note }`, от последнего известного поколения к следующему.

## Дракон (`dragons.json`)

`h` — год, когда вылупился (`ha: 1` — примерно), `hl` — подпись к нему; `d` — год смерти (дробная часть только
упорядочивает события Танца), `dl` — подпись; `dk` — год смерти, если точный неизвестен; `dx` — до какого года точно
или предположительно жил; `alive` — жив на конец книг. `o` — ветвь (id из `origins`), `par` — родитель-дракон.
`r` — всадники: `[id или имя, с какого года, по какой, как достался, 1 — начало приблизительное]`; `bond` — связь без
полёта: `[id, как]`. `col` — основной цвет и акцент; `cs` — откуда окрас: `book` (книги), `art` (художник со слов
Мартина), `ill` (иллюстрации), `name` (по имени); `colour` — окрас словами; `size` — размер; `ev` — `[год, текст]`.
`fights` — схватки: `{ a, b, y, place, both }`, `both` — погибли оба.

## Экранизации (`screen.json`)

`a` — роли: `[сериал, актёр по-русски, актёр в оригинале, пометка]`. Сериалы: `got` — «Игра престолов» (2011–2019),
`hotd` — «Дом Дракона» (с 2022), `kotsk` — «Рыцарь Семи Королевств» (2026).

## Вассалитет (`vassals.json`)

Годы дробные: 299.65 — Красная свадьба внутри 299 года. У дома: `al` — периоды фактической присяги
`[с, по, сюзерен, почему]`; `liege` — сюзерен по умолчанию; `ex` — годы существования дома.
