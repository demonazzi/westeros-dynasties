# Династии Вестероса

Интерактивное древо Таргариенов и великих домов Вестероса: древо по поколениям, драконы, хронология,
родословная, список и вассалитет. Одна страница на d3; исходники разложены по файлам и собираются в один HTML.

## Сборка и проверки

```
python3 tools/build.py            # → dist/artifact.html (для публикации) и dist/targaryen-tree.html (отдельный файл)
node tools/validate.js            # данные: ссылки, корни, дубликаты, тексты
node tools/data.js --sync         # после правки data/: порядок и заголовки в texts/, разделы для новых людей
node tools/smoke.js               # все вкладки в jsdom
node tools/check-scale.js         # шкала времени
node tools/check-labels.js        # подписи и пунктиры ни на что не наезжают
node tools/check-links.js         # связи между домами
node tools/check-vassal.js        # вкладка «Вассалитет»
node tools/check-minor.js         # малые дома: своя полоса, герб меньше; фильтр: блоки, края, «только», поиск
node tools/check-tips.js          # подсказка у линии связи не залипает
node tools/check-house.js         # карточка дома: открытие с древа, хронологии, списка, карточки человека; история
node tools/check-i18n.js          # английский: имена, интерфейс, данные, тексты, возврат к русскому
node tools/i18n-keys.js [en]      # строки интерфейса → src/i18n/en.json (обходит собранную страницу)
node tools/i18n-data.js           # строки данных → texts/en/data.json
node tools/check-time.js          # хронология: годы жизни и отметки браков в пределах, линии внутри полос
node tools/shot.js имя 1440 900 "js" dark   # скриншот в shots/
```
Проверки в браузере используют Playwright с Chromium (`/opt/npm-tools/node_modules/playwright`).

## Устройство

- `data/` — данные в JSON: полосы, дома и пропуски (`meta.json`), люди по домам (`people/*.json`), драконы,
  экранизации, вассалитет. Поля описаны в `data/README.md`.
- `texts/` — длинные тексты в Markdown: описания людей, домов (`vassals.md`) и драконов, отличия сериалов от книг.
  Раздел — `### id · Имя`.
- `tools/data.js` — загрузчик: склеивает `data/` и `texts/` в переменные страницы (`--emit`), раскладывает тексты (`--sync`).
- `data/vassals.json` — собирается `node tools/vassals-build.js` из `research/vassal/*.json`.
- `src/app-core.js` — ядро: данные, раскладка древа, карточка, поиск, история.
- `src/app-mod-*.js` — вкладки и модули (хронология, драконы, родословная, список, вассалитет, шкала, линзы, фильтры…).
- Карточка дома (`src/app-mod-house.js`) открывается кликом по гербу и названию полосы на древе и в хронологии,
  по названию дома в карточке человека, из списка и из «Вассалитета»; адрес `#h:код`. Текст о доме — `texts/vassals.md`,
  один на карточку и вкладку «Вассалитет» (426 домов); край и «Кому служил» — из вассалитета (поле `v` у дома в `meta.json`).
  Когда древо сдвинуто и заголовок полосы (герб и название) ушёл за левый край экрана, у края полосы виден маленький
  ярлык с гербом — тоже открывает карточку дома.
- `src/styles.css`, `src/body.html` — стили и разметка.
- `src/app-i18n.js`, `src/i18n/*.json`, `texts/en/` — английская версия (см. ниже).

## Источники

- Факты — A Wiki of Ice and Fire (awoiaf.westeros.org).
- Русские имена и названия — 7kingdoms.ru (только написание, не источник фактов).
- `research/` — сырой сбор: `vassal/` для вкладки «Вассалитет», `houses/` для домов Тиреллов и Грейджоев
  (`gen_houses.py`) и Фреев (`fry/` — бриф и сбор по частям, `gen_fry.js`). Генераторы одноразовые: после них
  данные правятся в `data/` и `texts/`.

## Тексты и черновики Claude

`✎` в конце заголовка раздела в `texts/` — текст написал Claude (черновик); на странице это `ai: 1`.
В карточке такие тексты помечены «✎ Черновик Claude», линза «Тексты Claude» подсвечивает их на древе.
Править можно прямо в `texts/*.md` (тогда `✎` стереть руками) или в присланном файле страницы:
```
node tools/texts-extract.js /путь/к/правленому.html /путь/edited.json
node tools/texts-merge.js /папка/с/edited.json     # переносит тексты в texts/; у изменённых снимает ✎
```

## Английская версия

Русский — исходный, английский — по словарям; что не переведено, показывается по-русски. Переключатель RU · EN
рядом с названием (выбор запоминается), `?lang=en` в адресе. Переключение перезагружает страницу с тем же адресом.

- `src/i18n/en.json` — интерфейс: «русская строка → перевод», в коде `App.t('видно {n} из {all}', { n, all })`,
  формы числа — ключ «дом|дома|домов»; разметка и всё дорисованное потом переводятся само (`App.translateDom`,
  `App.autoTranslate`).
- `texts/en/data.json` — строки данных (дома, девизы, заметки, причины присяги, приписки к бракам): «русская → { en, ctx }».
- `texts/en/**/*.md` — тексты людей, домов, драконов и экранизаций, те же разделы `### id · Name`; пустой — русский текст
  с пометкой. Имена людей и драконов — из поля `en`.
- Как переводить — `texts/en/README.md`. Новые строки: `node tools/i18n-keys.js`, `node tools/i18n-data.js`,
  `node tools/data.js --sync`.
