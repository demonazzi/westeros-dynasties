# Династии Вестероса

Интерактивное древо Таргариенов и домов Вестероса: 12 великих и 34 малых дома, 1031 человек, 27 драконов.
Вкладки: древо, драконы, хронология, родословная, список, присяги, карточки домов. Русский и английский.

English version of this file: [README.en.md](README.en.md).

Страница — один HTML-файл без сервера: `index.html` в корне (его публикует GitHub Pages). Снаружи грузятся только
d3 7.8.5 (cdnjs) и шрифты Google.

## Встроить на сайт

```html
<iframe src="https://demonazzi.github.io/westeros-dynasties/?lang=en#h:stk" style="width:100%;height:800px;border:0"></iframe>
```

| адрес | что откроется |
|---|---|
| `#robb` | человек на древе (id из `data/people/*.json`) |
| `#h:stk` | карточка дома (код дома из `data/meta.json`) |
| `#dragons`, `#d:balerion` | драконы, конкретный дракон |
| `#t:robb`, `#k:robb`, `#l:robb` | хронология, родословная, список — с выбранным человеком |
| `#v:130` | присяги на 130 г. |
| `?lang=en`, `?lang=ru` | язык |

## Сборка и проверки

Нужны Python 3 и Node.js 18+.

```
python3 tools/build.py        # → index.html, dist/targaryen-tree.html, dist/artifact.html
```
Сборка не пройдёт, если данные и тексты не сходятся, и напишет, что не так.

Проверки (для браузерных один раз: `cd tools && npm install && npx playwright install chromium`):
```
node tools/validate.js        # данные: ссылки на людей, корни полос, дубликаты
node tools/data.js --check    # data/ и texts/ сходятся
node tools/smoke.js           # все вкладки открываются; в выводе должно быть "errors": []
node tools/check-labels.js    # подписи и пунктиры не наезжают на карточки
node tools/check-time.js      # хронология: годы жизни и браки в пределах
node tools/check-minor.js     # малые дома и фильтр
node tools/check-vassal.js    # вкладка «Присяги»
node tools/check-house.js     # карточка дома
node tools/check-i18n.js      # английская версия
node tools/check-tips.js      # подсказки у линий
node tools/check-scale.js     # шкала времени (запускать отдельно)
node tools/check-links.js     # линии между домами (≈10 минут)
```

## Где что лежит

```
data/meta.json            дома, полосы древа, пунктиры-пропуски, порядок файлов людей
data/people/<дом>.json    люди (поля — data/README.md)
data/dragons.json         драконы
data/screen.json          актёры экранизаций
data/vassals.json         присяги — собирается из research/vassal/*.json, руками не править
texts/                    длинные тексты (Markdown): people/<дом>.md, vassals.md (дома), dragons.md, screen*.md
texts/en/                 то же по-английски + data.json (переводы коротких строк из data/)
src/                      код: app-core.js (древо, карточка, поиск), app-mod-*.js (вкладки и модули),
                          app-mod-sigils.js (гербы), styles.css (цвета домов), i18n/en.json (интерфейс по-английски)
tools/                    сборка, проверки, синхронизация текстов и переводов
research/                 сырой сбор и одноразовые скрипты; повторно не запускать (кроме research/vassal/)
```

`data/meta.json` отформатирован вручную, одна запись в строке: правьте его текстовым редактором, не пересохраняйте
через форматтер JSON. Файлы `data/people/*.json` можно и так, и так.

## Как поправить

После любой правки: `node tools/validate.js`, `python3 tools/build.py`, открыть `dist/targaryen-tree.html`.
Все поля человека описаны в `data/README.md`; ниже — частые случаи.

### Имя

В `data/people/<дом>.json` у человека: `name` — имя на карточке, `full` — полное (с прозвищем или титулом, если
отличается), `en` — английское имя (показывается в английской версии и ищется на A Wiki of Ice and Fire),
`al` — другие имена для поиска, `wiki` — точное название страницы на вики, если `en` неоднозначно.
Потом `node tools/data.js --sync` — обновит имя в заголовках текстов.

### Родители и место на древе

- `p` — под кем человек стоит на древе (id). Перенести к другому родителю — поменять `p`.
- `par` — оба родителя: id или просто текст, если у родителя нет карточки; пометки в скобках после id:
  `["aegon4 (по слухам)", "Лукас Лотстон (официально)", "falena"]`.
- `rp` — родитель по слухам из другого дома (рисуется отдельной линией); `unc: 1` — родство не подтверждено
  (пунктир к родителю).
- Порядок детей на древе — порядок записей в файле.
- Человек без родителя на древе — корень полосы: убрать `p` и добавить в `data/meta.json` → `bands` → его дом →
  `roots`: `["id", колонка]`. Колонка — поколение, примерно год рождения:

  | колонка | 6 | 8 | 10 | 12 | 14 | 16 | 18 | 19 | 20 |
  |---|---|---|---|---|---|---|---|---|---|
  | год | −20 | 34 | 88 | 123 | 172 | 198 | 245 | 269 | 286 |

### Браки, помолвки, связи

`sp` у человека: `[[кто, примечание, тип]]`. «Кто» — id (тогда рисуется линия) или имя текстом (супруг без карточки).
Тип: `m` — брак (можно не писать), `b` — помолвка, `l` — связь вне брака. «N г.» в примечании читается как год брака.
В карточке человека показывается только его собственный `sp`, поэтому запись нужна у обоих супругов.
`wd` — воспитанники (список id).

### Годы

`b` — рождение, `d` — смерть; от Завоевания, до него — отрицательные. Можно: `"256–263"`, `"245/246"` (один из двух),
`"не ранее 101"`, `"не позднее 283"`, `"≈286"`, `"в детстве"`, `"в младенчестве"`, `"при рождении"`.
Если года смерти нет: `alive: 1` — жив на конец книг; `ls: 280` — последний год, когда точно жив.

### Пропуск в линии

Пунктир между двумя людьми одного дома, когда промежуточные лорды не названы — `data/meta.json` → `gaps`:
`{"house":"stk","from":"id","to":"id","years":"≈ 40 лет","note":"подпись"}`. `from` должен стоять левее `to`;
`node tools/check-labels.js` покажет, если пунктир пересекает чужую карточку.

### Присяги (кто кому служил)

Источник — `research/vassal/<край>.json`, массив `houses`. У дома: `en` (название), `page` (страница на вики;
из неё делается id дома: `House_Mallister` → `mallister`), `ru`, `seat_en`, `seat_ru`, `great`, `from`/`to` (годы
существования дома), `liege` — сюзерен по умолчанию (английское название дома или `throne`), `allegiance` —
отрезки, когда сюзерен другой: `{"from":129,"to":131,"liege":"blacks","why":"почему"}`. Особые сюзерены:
`throne`, `blacks`, `greens`, `blackfyre`, `rebels`, `robb`, `renly`, `stannis`, `balon`, `euron`, `aegon_young`,
`neutral`, `independent`. Претенденты, великие дома и вехи — в `research/vassal/top.json`. После правки:
```
node tools/vassals-build.js   # пересоберёт data/vassals.json и напишет, что не нашёл
node tools/data.js --sync     # разделы для новых домов в texts/vassals.md
```

### Новый человек

1. Запись в `data/people/<дом>.json` в нужную группу: минимум `id` (латиницей, уникальный), `name`, `en`,
   `hs` (код дома; Таргариенам можно не писать), `k` (`T` — обычный, `K` король, `C` претендент, `R` бастард),
   `p`, `par`.
2. `node tools/data.js --sync` — появятся пустые разделы для текста в `texts/people/<дом>.md` и `texts/en/people/<дом>.md`.
3. `node tools/i18n-data.js` — новые русские строки (имена без карточек, примечания) попадут в `texts/en/data.json`
   с пустым `en`; вписать перевод.

### Новый дом

1. `data/meta.json` → `houses`: `"код": {"v":"id дома в присягах","name":"Дом …","band":"подпись полосы",
   "motto":"Замок · «Девиз»","sigil":{"field":"#цвет поля","charge":"#цвет фигуры"}}`.
2. Там же → `bands`: `{"house":"код","liege":"код великого дома","roots":[["id",колонка]]}` (`liege` — только у малого
   дома, полоса берёт его цвет) и код в `people_files`.
3. `data/people/код.json`: `{"title":"…","about":"…","groups":[{"title":"…","people":[…]}]}`.
4. Герб: функция в словаре `FIG` в `src/app-mod-sigils.js` (рисует фигуру внутри щита 64×76); без неё — общий щит.
   Цвет полосы великого дома — переменные `--код` и `--код-tint` в начале `src/styles.css` (в трёх местах:
   общие и два тёмных варианта).
5. Если дома ещё нет в присягах — добавить в `research/vassal/<край>.json` и `node tools/vassals-build.js`.
6. `node tools/data.js --sync`, `node tools/i18n-data.js` (перевести название, подпись полосы, девиз), сборка,
   `node tools/check-minor.js`, `node tools/check-labels.js`.

### Тексты

Тексты — в `texts/` (по-русски) и `texts/en/` (по-английски), формат — в `texts/README.md`. Раздел начинается строкой
`### id · Имя`; её не менять, текст — строки под ней. `✎` в конце этой строки — черновик, написан нейросетью
(на странице помечен); убрать знак, когда текст проверен.

### Надписи интерфейса

В коде — через `App.t('русская строка')`. После правок `node tools/i18n-keys.js` добавит новые строки
в `src/i18n/en.json`; перевод вписать туда (ключ — русская строка, значение — английская).

### Драконы

`data/dragons.json`: `origins` — ветви, откуда драконы (`{"id","name","y"}`), `groups` — группы с драконами,
`fights` — схватки `{"a","b","y","place","both"}` (`a`, `b` — id драконов, `both: 1` — погибли оба).

Поля дракона: `id`, `name`, `en`, `sex` (`f`/`m`), `o` — ветвь (id из `origins`), `par` — дракон-родитель;
`h` — год, когда вылупился (`ha: 1` — примерно), `hl` — подпись к нему; `d` — год смерти (дробная часть только
упорядочивает события одного года), `dl` — подпись, `dk` — год смерти, если точный неизвестен, `dx` — до какого года
точно жил, `alive: 1` — жив на конец книг; `r` — всадники: `[id или имя, с какого года, по какой, как достался,
1 — начало приблизительное]`; `bond` — связь без полёта: `[id, как]`; `col` — два цвета, основной и акцент;
`cs` — откуда окрас (`book` книги, `art` художник со слов Мартина, `ill` иллюстрации, `name` по имени);
`colour`, `size` — окрас и размер словами; `ev` — события `[год, текст]`.

У человека поле `dr` — подпись дракона в его карточке. Новый дракон: запись в нужную группу, затем
`node tools/data.js --sync` (разделы в `texts/dragons.md` и `texts/screen-dragons.md`) и `node tools/i18n-data.js`.

### Экранизации

`data/screen.json`: `series` — сериалы (`got`, `hotd`, `kotsk`), `groups` — роли `{"id": id человека, "a": [[сериал, актёр по-русски,
актёр в оригинале, пометка]]}`. Отличия сериала от книг — тексты в `texts/screen.md` (люди) и
`texts/screen-dragons.md` (драконы).
