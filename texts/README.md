# Тексты: формат

Длинные тексты страницы, по-русски: люди — `people/<дом>.md`, дома — `vassals.md` (один текст на карточку дома
и вкладку «Присяги»), драконы — `dragons.md`, отличия экранизаций от книг — `screen.md` (люди) и
`screen-dragons.md` (драконы). Английские — те же файлы в `en/`. Короткие строки (имена без карточки, девизы,
примечания к бракам) — не здесь, а в `data/`.

```markdown
### stark · Старки ✎
Текст — строки под заголовком.
```

- Заголовок `### id · Имя` служебный: id не менять, имя подставляется само. Разделы не добавлять, не удалять и не
  переставлять руками: `node tools/data.js --sync` создаёт их сам, когда в `data/` появился человек, дом или дракон.
  Строки `#`, `##` и комментарии `<!-- … -->` не трогать.
- `✎` в конце заголовка — черновик, написан нейросетью: на странице у текста пометка «✎ Черновик», линза
  «Черновики» подсвечивает такие карточки. Убрать знак — пометка пропадёт.
- Простой текст без разметки Markdown. У людей — один абзац; у домов (`vassals.md`) можно несколько, через пустую
  строку.
- Пустой раздел — на странице текста нет (в английской версии вместо него покажется русский с пометкой).

После правки:
```
node tools/data.js --check     # разделы целы, лишних нет
python3 tools/build.py
```

Если тексты правили прямо в собранной странице (в копии HTML), перенести их сюда:
```
node tools/texts-extract.js /путь/к/правленому.html /путь/edited.json
node tools/texts-merge.js /папка/с/edited.json     # переносит в texts/; у изменённых снимает ✎
```
