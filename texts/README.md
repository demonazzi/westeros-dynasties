# Тексты: как править

Тексты страницы лежат здесь в Markdown: люди — `people/*.md`, дома — `vassals.md`, драконы — `dragons.md`,
отличия экранизаций — `screen.md`, `screen-dragons.md`. Английские — в `en/` (как переводить — `en/README.md`).

## Формат (общий для всех файлов)

```markdown
### stark · Старки ✎
Текст одним абзацем — строки под заголовком.
```
- Заголовок `### id · Имя` служебный: **id не менять**, имя подставляется само. Разделы не добавлять, не удалять,
  не переставлять. Строки `#`, `##` и комментарий `<!-- … -->` не трогать.
- `✎` в конце заголовка — черновик Claude. Поправил(а) текст — **сотри ✎**, тогда на странице пропадёт пометка
  «Черновик Claude». Не правил(а) — ✎ оставить.
- Текст — один абзац обычного текста, без Markdown-разметки, списков и ссылок. Кавычки — «ёлочки», тире — «—».
- Годы — от Завоевания: «130 г.», «2 г. до З.», диапазон «129–131».
- Пустой раздел — на странице «Текст о доме ещё не написан».

## Тексты о домах — `vassals.md`

Один текст на дом: его показывают и вкладка «Вассалитет», и карточка дома на древе. 426 разделов по краям
(Север, Речные земли…). Сейчас там рабочие заметки, собранные при разборе A Wiki of Ice and Fire: в них много
служебного. Задача — превратить каждую в короткий связный текст о доме для читателя.

**Каким должен быть текст**
- Энциклопедично, прошедшее время, 2–5 предложений (примерно 250–700 знаков); у малоизвестных домов — одно-два.
- Что писать: кто такие (край, замок, чьи знаменосцы), чем известны, главное из истории — по порядку лет
  (Завоевание, Танец драконов, восстания Блэкфайров, Восстание Роберта, Война пяти королей), известные люди дома.
- Подробный список «кому служил по годам» показывается на странице отдельно, повторять его целиком не нужно —
  достаточно главных поворотов.

**Что убрать**
- Служебное и ссылки на источник: «AWOIAF», «по AWOIAF», «страница AWOIAF — …», «карточка на вики», «Overlord»,
  «сегмент(ы)», «для карты», «дубликат», «исследуется/изучается отдельно», «верхний уровень», «без книжного тега»,
  «категория …», стрелки «->», английские слова и названия страниц.
- Рассуждения о данных: «AWOIAF года не указывает — отнесено ко всей войне», «полуканон», «в карточке вики
  сюзерены — …». Если факт сомнительный — либо убрать, либо сказать по-человечески: «по некоторым сведениям»,
  «в книгах год не назван».

**Чего не делать**
- Не выдумывать. Факты — только из самой заметки или с A Wiki of Ice and Fire (awoiaf.westeros.org). Не уверен(а) —
  лучше короче.
- Не брать факты из сериалов и игр.
- Русские имена, названия замков и домов — как на 7kingdoms.ru и как уже написано в файлах проекта
  (`people/*.md`, этот файл): «Эйегон», «Риверран», «Близнецы». Не переводить заново с английского.

**Пример**

Было:
```
### westerling · Вестерлинги ✎
Древний род эпохи Первых Людей, бывшие жёны королей Утёса. Мятеж принца Эйегона против Мейгора I (43): присоединились к Эйегону; … AWOIAF даёт событие без года.
```
Стало:
```
### westerling · Вестерлинги
Древний дом Первых Людей из Западных земель, знаменосцы Ланнистеров; их замок — Скала. В 43 г. Вестерлинги
поддержали принца Эйегона против Мейгора I, а в 49 г. Джейн Вестерлинг принудили выйти за самого Мейгора. Роланд
Вестерлинг входил в совет при Эйегоне III; в 261 г. дом поддержал Тайвина Ланнистера против Рейнов и Тарбеков,
а сир Элис Вестерлинг участвовал в Разграблении Королевской Гавани в 283 г.
```
(Текст — одним абзацем; здесь перенесён только для чтения. Все факты примера — из заметки этого дома.)

**Как сдавать.** Удобно по одному краю (разделу `##`) за раз; вернуть файл целиком. Проверка после правки:
```
node tools/data.js --check     # разделы целы, лишних нет
python3 tools/build.py         # сборка
```
